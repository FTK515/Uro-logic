URO logic by FTK — iPad PWA v34

This package is prepared for iPad 10th generation in landscape mode.

INSTALLATION:
1. Host the folder on an HTTPS website. A service worker cannot be installed from a local file or from a file:// URL.
2. On iPad, open the HTTPS address in Safari.
3. Tap Share -> Add to Home Screen -> Add.
4. Launch URO logic from the Home Screen.

IMPORTANT:
- The ZIP itself is not directly installable as a PWA on iPad.
- The medical images are embedded in index.html and are not externally dependent.
- The app is designed for touch/Apple Pencil interaction and landscape use.
